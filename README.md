🏥 Sistem Antrean Puskesmas Menggunakan Priority Queue
Deskripsi Proyek :
Sistem Antrean Puskesmas adalah aplikasi berbasis Python dan Streamlit yang digunakan untuk mengelola antrean pasien berdasarkan tingkat prioritas pelayanan.
Pada pelayanan kesehatan, beberapa kategori pasien harus mendapatkan pelayanan lebih dahulu dibandingkan pasien lainnya. Oleh karena itu, aplikasi ini menerapkan struktur data Priority Queue sehingga pasien dengan prioritas lebih tinggi akan dipanggil terlebih dahulu meskipun datang setelah pasien lain.
Aplikasi ini dibuat sebagai implementasi konsep Queue (Antrian) pada mata kuliah Struktur Data.

Fitur Aplikasi :
Pendaftaran Pasien
Petugas dapat memasukkan:
1.Nama pasien
2.Kategori pasien
Kategori yang tersedia:
1.Darurat
2.Lansia
3.Ibu Hamil
4.Umum
Setelah mendaftar, pasien akan memperoleh nomor antrean otomatis.

Menampilkan Antrean
Aplikasi menampilkan antrean berdasarkan kategori:
1.Antrean Darurat
2.Antrean Lansia
3.Antrean Ibu Hamil
4.Antrean Umum

Pemanggilan Pasien
Saat tombol "Panggil Pasien Berikutnya" ditekan, sistem akan:
1.Mengecek antrean Darurat
2.Jika kosong, mengecek Lansia
3.Jika kosong, mengecek Ibu Hamil
4.Jika kosong, mengecek Umum
Pasien yang dipanggil akan dihapus dari antrean.


Kesimpulan :
Aplikasi Sistem Antrean Puskesmas dibuat untuk membantu mengelola antrean pasien secara terstruktur berdasarkan tingkat prioritas pelayanan.
Sistem ini memungkinkan pasien dengan kondisi darurat, lansia, dan ibu hamil mendapatkan pelayanan lebih cepat dibandingkan pasien umum.
Proyek yang dibuat untuk memenuhi tugas ulangan akhir semester struktur data pemrograman.
